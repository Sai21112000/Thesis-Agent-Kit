## Section 1 — Terminology Bank

| Term | Precise Definition |
|------|-------------------|
| Qualitative Coding | Systematic labeling of data segments with conceptual tags |
| Open Coding | Initial unrestricted code generation from raw data |
| Axial Coding | Relating codes to each other through categories and subcategories |
| Selective Coding | Identifying core category that integrates all other categories |
| Thematic Analysis | Method for identifying, analyzing, and reporting patterns (themes) in data |
| Grounded Theory | Systematic methodology generating theory from data through iterative comparison |
| Reflexivity | Researcher's critical self-examination of their role, biases, and influence on the study |
| Positionality | Researcher's social and political context relative to the research setting |
| Triangulation | Using multiple data sources, methods, or investigators to enhance credibility |
| Saturation | Point at which no new themes or codes emerge from additional data |
| Thick Description | Rich, detailed account of experiences and contexts enabling transferability |
| Member Checking | Returning findings to participants to verify accuracy and resonance |
| Bracketing | Setting aside researcher's preconceptions to approach data without bias |
| Phenomenology | Study of structures of consciousness and lived experience |
| Ethnography | Immersive study of cultural groups through prolonged engagement |
| Case Study | In-depth investigation of a bounded system (person, group, organization) |
| Purposive Sampling | Deliberate selection of participants based on specific criteria |
| Snowball Sampling | Recruiting participants through referrals from existing participants |
| Theoretical Sampling | Selecting cases based on emerging theory (grounded theory) |
| In Vivo Code | Code using participant's own words |
| Narrative Analysis | Examining stories and accounts to understand meaning-making |
| Discourse Analysis | Examining language use in social contexts to reveal power structures |

## Section 2 — Trustworthiness Criteria (Lincoln & Guba, 1985)

Replaces quantitative validity/reliability for qualitative research:

| Criterion | Quantitative Parallel | Strategies |
|-----------|----------------------|------------|
| Credibility | Internal validity | Prolonged engagement, triangulation, member checking, peer debriefing |
| Transferability | External validity | Thick description, purposive sampling, detailed context |
| Dependability | Reliability | Audit trail, code-recode procedure, inter-coder agreement |
| Confirmability | Objectivity | Reflexive journal, triangulation, audit trail |

### Inter-Coder Reliability
Cohen's kappa (two coders): kappa >= 0.61 acceptable, >= 0.81 excellent
Krippendorff's alpha (multiple coders): alpha >= 0.667 acceptable, >= 0.80 good
Report: initial agreement rate, kappa/alpha, disagreement resolution process

### Thematic Saturation
Document: at which interview/data point no new codes emerged
Report total codes generated and final theme count

## Section 3 — Chapter 3 Checklist

- [ ] Research paradigm stated (interpretivism, constructivism, pragmatism, critical theory)
- [ ] Methodology named with citation (thematic analysis, grounded theory, phenomenology, etc.)
- [ ] IRB/Ethics approval: committee name, approval number, date
- [ ] Informed consent: procedure, voluntary participation, right to withdraw
- [ ] Participant selection: sampling strategy with rationale
- [ ] Participant demographics: age range, gender, relevant characteristics (anonymized)
- [ ] Sample size with saturation justification
- [ ] Data collection method: interviews/focus groups/observations/documents
- [ ] Interview guide or observation protocol (appended or described)
- [ ] Recording and transcription method
- [ ] Coding procedure: initial, focused/axial, theoretical (with software if used)
- [ ] Coding scheme development: deductive, inductive, or hybrid
- [ ] Inter-coder reliability: method, coders, agreement metric
- [ ] Reflexivity statement: researcher positionality and potential biases
- [ ] Trustworthiness strategies: which of the 4 criteria and how addressed
- [ ] Data management and confidentiality measures

## Section 7 — Forbidden Phrases

| Forbidden | Correct |
|-----------|---------|
| "The data proves" | "The findings suggest" or "The analysis indicates" |
| "participants felt" (without evidence) | "Participant 3 stated: '[quote]', reflecting [theme]" |
| "generalizable results" | "transferable to [specified contexts] given [thick description]" |
| "unbiased researcher" | "Reflexive measures were employed to address researcher positionality" |
| "all participants agreed" | "[N] of [total] participants expressed [theme] (see Table X)" |
| "objective findings" | "Trustworthiness was established through [specific strategies]" |
| "I interviewed people" | "Semi-structured interviews were conducted with [N] participants" |

## Section 8 — Reflexivity Statement Template

"The researcher identifies as [relevant demographic/professional characteristics].
Prior experience with [topic/population] included [specifics].
To mitigate potential bias, [strategies employed]: maintaining a reflexive journal,
conducting member checking with [N] participants, and engaging in peer debriefing
with [colleague/advisor]. The researcher's positionality as [insider/outsider]
to the study context was [acknowledged/addressed] through [specific measures]."

## Error Handling

Ethics/IRB approval absent:
-> BLOCK: "Ethics approval required before drafting Methods. Add IRB details to PROJECT-CONFIG.md."

Reflexivity statement absent:
-> Flag: "[REFLEXIVITY MISSING — add researcher positionality statement to Chapter 3]"

Saturation not documented:
-> Flag: "[SATURATION NOT DOCUMENTED — specify at which data point no new codes emerged]"

Trustworthiness criteria not addressed:
-> Flag: "[TRUSTWORTHINESS NOT ADDRESSED — document credibility, transferability, dependability, and confirmability strategies]"

Quotes without participant IDs:
-> Flag: "[PARTICIPANT ID MISSING — attribute all quotes to anonymized participant identifiers]"
